#  PreHier

### AI-Powered Pre-Hire Screening System

PreHier is an AI-powered candidate screening system that analyzes job descriptions and resumes, compares candidate qualifications against job requirements, evaluates supporting evidence and project relevance, and generates an explainable candidate match score.

## 🚀 Features

* 📋 **Job Description Analysis**

  * Extracts required skills
  * Extracts preferred skills
  * Identifies required experience
  * Identifies education requirements

* 📄 **Resume Analysis**

  * Extracts text from PDF resumes
  * Generates structured candidate profiles
  * Extracts skills, education, experience, projects, certifications, and achievements

* 🎯 **Required Skill Matching**

  * Compares candidate skills against required skills
  * Identifies matched and missing skills
  * Generates a required skill score

* ⭐ **Preferred Skill Matching**

  * Separately evaluates preferred qualifications
  * Identifies matched and missing preferred skills

* 🧠 **Evidence-Based Screening**

  * Evaluates whether candidates provide evidence for job requirements
  * Classifies evidence as Strong, Partial, or None
  * Provides an explanation for each requirement

* 📁 **Project Relevance**

  * Evaluates candidate projects against the job profile
  * Determines project relevance as Strong, Partial, or None
  * Provides reasoning for each project

* 🏆 **Candidate Scoring**

  * Combines multiple screening signals into an overall score
  * Uses deterministic Python-based scoring
  * Provides a transparent score breakdown

## 🧮 Scoring Model

The current scoring model uses the following weights:

| Component         |   Weight |
| ----------------- | -------: |
| Required Skills   |      40% |
| Preferred Skills  |      15% |
| Experience        |      15% |
| Education         |      10% |
| Project Relevance |      20% |
| **Total**         | **100%** |

The final score is calculated by the Python scoring engine rather than being directly generated by the LLM.

## 🔄 Screening Pipeline

```text
1. Recruiter enters Job Description
            ↓
2. AI extracts Job Profile
            ↓
3. Recruiter uploads Resume PDF
            ↓
4. Resume text is extracted
            ↓
5. AI creates Candidate Profile
            ↓
6. Required Skills are matched
            ↓
7. Preferred Skills are matched
            ↓
8. Requirement evidence is evaluated
            ↓
9. Project relevance is evaluated
            ↓
10. Experience and Education are scored
            ↓
11. Overall Candidate Score is calculated
            ↓
12. Results are displayed in Streamlit
```

## ⚙️ Setup

Clone the repository:

```bash
git clone <your-repository-url>
cd PreHier-AI
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file and add your Groq API key:

```env
GROQ_API_KEY=your_api_key_here
```

Run the application:

```bash
python -m streamlit run app.py
```

The application will open in your browser.
